# 英语听力练习网站 — 设计文档

版本：v1.0　日期：2026-09-15　配套：[需求文档.md](./需求文档.md)

## 1. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + Vite + TypeScript + Pinia + Element Plus | SPA，音频播放用原生 Audio |
| 后端 | Python 3.11 + FastAPI + Uvicorn | REST API |
| 业务数据库 | SQLite (SQLAlchemy) | 句子、答题记录、设置 |
| 向量数据库 | Chroma（嵌入式，persist 目录本地落盘） | 句子向量：去重、相似检索 |
| TTS | edge-tts（`en-US-AriaNeural` / `en-US-GuyNeural`） | 美式发音，rate 可调 |
| LLM | 智谱 GLM（`zhipuai` SDK，模型 glm-4-flash） | 生成句子与干扰项 |
| Embedding | Chroma 默认（all-MiniLM-L6-v2, 本地推理) | 无需额外 API |

## 4. 数据模型

### 4.1 SQLite

```sql
-- 难度等级（预置 L1~L5，可扩展）
difficulty_levels(id PK, code TEXT UNIQUE,        -- 'L1'...'L5'
                  ielts TEXT, cefr TEXT, label TEXT)

sentences(id PK,
          text TEXT UNIQUE,        -- 英文原文
          translation TEXT,        -- 中文释义
          difficulty_id FK,
          topic TEXT,
          voice TEXT DEFAULT 'en-US-AriaNeural',
          created_at TIMESTAMP)

attempts(id PK,
         sentence_id FK,
         correct INTEGER,          -- 0/1
         chosen_text TEXT,         -- 用户所选选项
         created_at TIMESTAMP)     -- 答题时间

settings(key TEXT PK, value TEXT)  -- 默认难度/主题/声音/语速
```

sentences 冗余统计字段（由 attempts 聚合或触发器维护）：`wrong_count INT`、`total_count INT`、`last_reviewed_at TIMESTAMP`，用于抽题加权，避免每次全表聚合。

### 4.2 Chroma

- Collection：`sentences`
- document：英文原句；id：sentence_id（字符串）
- metadata：`{difficulty, topic, created_at}`
- 用途：
  1. **入库去重**：新句 query 最相似 top1，余弦距离 < 0.08（相似度 > 0.92）则拒绝入库并重新生成；
  2. 相似句推荐（后续扩展）。

## 5. API 设计

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/sentences/generate` | body: `{difficulty, topic, count}` → LLM 生成、去重、入库、合成音频，返回句子列表 |
| GET | `/api/sentences` | 分页列表，filter: difficulty/topic/keyword |
| DELETE | `/api/sentences/{id}` | 删除句子 + 向量 + 音频文件（级联删 attempts） |
| GET | `/api/audio/{id}?rate=0.75` | 返回 mp3。缓存文件按基准语速 1.0 存一份；非 1.0 语速实时合成（edge-tts 磁盘缓存 key 含 rate） |
| GET | `/api/quiz/next` | query: difficulty?, topic? → 加权随机抽 1 句；返回 `{quiz_id, audio_url, options: [4 个选项, 乱序]}`（不返回正确答案） |
| POST | `/api/quiz/submit` | body: `{quiz_id, chosen_text}` → 服务端比对 session 缓存的正确答案，写 attempts，返回 `{correct, original, translation}` |
| GET | `/api/stats` | 总句数、难度分布、正确率、近 7 天曲线、错题 TOP10 |
| GET/PUT | `/api/settings` | 读写默认设置 |

quiz_id 对应的正确答案存后端内存 dict（TTL 1 小时），防止前端作弊。

## 6. 关键流程

### 6.1 生成句子

1. 前端提交难度+主题 → 后端按难度构造 prompt（词汇量、句长、语法复杂度、是否含习语的分级描述）调用 GLM，一次生成 count 句（含中文翻译，JSON 输出）。
2. 逐句：Chroma 相似度去重（过近则让 LLM 补生成，最多重试 2 次）→ 写 SQLite + Chroma → edge-tts 合成 `data/audio/{id}_1.0.mp3`。
3. 返回句子与音频 URL。

### 6.2 出题（quiz/next）

1. SQL 加权随机抽 1 句：
   `weight = 1 + 2*wrong_count + days_since_last_review*0.5 + (从未考过 ? 3 : 0)`，按权重随机。
2. 干扰项：优先取该句预生成的干扰项缓存表；否则调用 LLM prompt（近音词替换 / 相似句式 / 同话题混淆，长度相近，与原文语义可区分）生成 3 个，做编辑距离校验（与原文相似度 > 0.85 的重生成）。
3. 4 选项乱序返回，正确答案进内存 session。

### 6.3 TTS

- edge-tts 异步合成：`communicate(text, voice, rate="+0%"/"-25%"...)`；rate 百分比由前端 0.5x/0.75x/0.85x/1.0x 映射。
- 缓存：`data/audio/{sentence_id}_{rate}.mp3`，存在即直接返回。

## 7. 前端设计要点

- AudioPlayer 组件：播放/暂停、重播、语速切换（换 audio src 的 rate 参数）、波形占位动画。
- 练习页：默认隐藏原文，"播放"→ 用户自测 → "显示原文/翻译"。
- 测验页：音频 + 4 个选项卡片，点击后高亮对错，显示解析，"下一题"。
- Pinia 持久化设置到 localStorage + 同步后端 /api/settings。

## 8. 错误处理与边界

- 智谱 API 失败/超时：返回 502，前端提示"生成失败请重试"；Key 缺失时启动日志警告。
- edge-tts 偶发网络失败：重试 2 次，仍失败则句子入库但标记无音频，列表可重新触发合成。
- 知识库为空时请求抽题：返回 404 + 提示先生成句子。
- 删除句子时同步删 Chroma 向量与音频文件，事务保证 SQLite 一致性。

## 9. 实施路线图

1. 阶段一：脚手架（前后端项目初始化、依赖、目录）。
2. 阶段二：后端（db → tts → llm → sentences → quiz → stats）+ pytest 冒烟。
3. 阶段三：前端（AudioPlayer → 练习页 → 测验页 → 统计/知识库/设置）。
4. 阶段四：联调、真实生成 5 个难度各若干句、全流程验收。
