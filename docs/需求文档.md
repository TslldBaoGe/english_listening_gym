# 英语听力练习网站 — 需求文档（PRD）

版本：v1.0　日期：2026-09-15

## 1. 项目背景与目标

为个人英语听力训练构建一个本地部署的网站。核心目标：

1. **难度可自定义**：按雅思（IELTS）听力分数段设定难度，也可映射到 CEFR 等级。
2. **纯正美式发音**：句子由专业级 en-US 声音朗读（Microsoft Aria / Guy，Edge-TTS），发音标准、自然，接近美国本地人的水平。
3. **知识库永不遗忘**：每次生成的新句子永久存入知识库（SQLite + Chroma 向量库），后续复习随时可抽取。
4. **随机抽考复习**：系统从知识库随机（带复习权重）抽取句子，以选择题形式考核听力理解，并记录答题情况。

## 2. 用户角色

单用户（本人使用），本地部署，无需注册登录。

## 3. 难度体系

| 难度等级 | 雅思对标 | CEFR | 句子特征 |
|---|---|---|---|
| L1 入门 | 5.0 | B1 | 简单句，常用词汇 1500 以内，语速较慢，无习语 |
| L2 基础 | 5.5–6.0 | B1+ | 常见复合句，日常话题 |
| L3 进阶 | 6.5 | B2 | 从句嵌套，学术与生活场景，含常见搭配 |
| L4 高阶 | 7.0 | C1 | 长难句，学术讲座风格，含习语与连读 |
| L5 挑战 | 7.5+ | C2 | 高语速、复杂结构、口语句式、专业话题 |

- 用户生成句子时选择难度等级 + 主题（如日常对话、校园、旅行、科技、职场、新闻等，可自定义输入）。
- 朗读语速可调：0.5x / 0.75x / 0.85x / 1.0x（Edge-TTS rate 参数）。

## 4. 用户故事与功能需求

### 4.1 生成新句子（学习模式）

- **US-1**：作为用户，我选择难度和主题后点击"生成"，系统调用 LLM（智谱 GLM）生成 1–3 个符合难度的英语句子。
- **US-2**：生成后自动入库：SQLite 保存原文、难度、主题、翻译（中文释义）、生成时间；Chroma 保存句子向量（用于去重与相似检索）。
- **US-3**：入库后自动用 Edge-TTS（en-US，Aria/Guy 声音）合成音频并缓存为 mp3，页面可播放、重播、调整语速。
- **US-4**：显示原文与中文翻译（可先隐藏，点击"查看原文"再显示，先自测听力）。
- **去重需求**：新句子入库前做向量相似度检索（阈值 0.92），过近则要求重新生成，避免知识库重复。

### 4.2 复习考核（测验模式）

- **US-5**：作为用户，我进入复习页，点击"开始测验"，系统从知识库随机抽取一句。
  - 抽样规则：加权随机 —— 答错次数多、距上次复习时间久的句子命中概率更高；从未考过的新句子有保底概率。
- **US-6**：页面只播放音频（可重播、可调语速），不显示原文。
- **US-7**：选择题考核：给出 4 个选项（1 个正确原文 + 3 个干扰项），干扰项由 LLM 生成（近音词替换、相似句式、同话题混淆），点击作答后立即判分。
- **US-8**：答完后显示正确答案、原文、翻译；答错自动把错误次数 +1。
- **US-9**：可连续测验（下一题），也可限定难度/主题范围抽题。

### 4.3 统计与知识库管理

- **US-10**：统计页展示：总句数、按难度分布、总答题数、正确率、最近 7 天练习曲线、错题最多的句子 TOP10。
- **US-11**：知识库列表页：浏览/搜索全部句子（按难度、主题、关键词过滤），可手动删除（同步删除向量与音频）。

### 4.4 设置

- **US-12**：可设置默认难度、默认主题、TTS 声音（Aria 女 / Guy 男）、默认语速。
- LLM API Key 通过环境变量 `ZHIPU_API_KEY` 配置，不进页面。

## 5. 功能清单汇总

| 模块 | 功能 |
|---|---|
| 句子生成 | 难度+主题选择、LLM 生成、向量去重、入库 |
| 朗读 | Edge-TTS en-US 合成、mp3 缓存、语速调节、声音选择 |
| 复习测验 | 加权随机抽题、4 选 1 选择题、AI 干扰项、即时判分 |
| 统计 | 难度分布、正确率、练习曲线、错题榜 |
| 知识库 | 列表、搜索、过滤、删除 |
| 设置 | 默认参数持久化 |

## 6. 非功能需求

1. **本地部署**：前端 + 后端均运行在本机（localhost），单用户。
2. **性能**：音频首次合成 ≤ 3 秒，命中缓存 < 100ms；出题接口 ≤ 2 秒（含 LLM 生成干扰项时可预生成/异步）。
3. **持久性**：知识库数据（SQLite + Chroma + 音频文件）永久保留，升级不丢数据。
4. **可扩展**：难度等级、主题可后续扩充；预留听写模式接口。

## 7. 范围外（本期不做）

- 多用户与登录
- 移动端 App
- 听写填空模式（列为后续路线图）
- 口语跟读评分
