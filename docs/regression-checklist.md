# 前端回归检查清单

> 每次改动前端代码后、推送前，按此清单核对核心功能。任何一项不过，先修再推。
> 起因：2026-10-11 重构音频时破坏了循环播放与互斥，用户明确要求"不能再影响之前正常的功能"。

## 播放器（最易回归，改动音频/播放器后必查）
- [ ] **互斥**：任一卡片播放中，点另一卡片播放 → 前一句立刻停止并归零（练习、测验、知识库三页都验）。
- [ ] **循环**：打开循环开关 → 播放 → 播到结尾自动从头再来；关闭 → 播完即停。
- [ ] **循环全局同步**：练习页开循环 → 切到知识库页再回来 → 循环仍为开（知识库页的播放器也绑定了 store.loop，不会把全局状态顶掉）。
- [ ] **倍速**：切 0.5x/0.85x 等 → 请求的音频 URL 带对应 rate；正在播时切倍速继续播。
- [ ] 同一句连点播放键 = 暂停/继续。

## 生成 / 抽题 / 听写
- [ ] 「生成并朗读」：生成后自动念第一句；生成多句只自动念第一句。
- [ ] 生成失败（断网/接口错）有错误提示，页面不崩。
- [ ] 测验「抽取句子」：抽到的句子不与已展示的重复；「包含已掌握的」勾选生效。
- [ ] 「只练未掌握主题」模式：切换后主题选择隐藏、提示未掌握主题列表；生成的句子覆盖这些主题词并自动朗读。
- [ ] 听写提交：全对标记已掌握；答错不给答案，可点「看答案」。

## 页面状态记忆（首帧无跳变）
- [ ] 练习：难度/主题/声音/数量/句子列表，刷新与切页后保留；第一帧就是上次的值（无默认值闪现）。
- [ ] 测验：抽题、作答、判定结果保留。
- [ ] 统计：上次数据首帧显示，后台刷新。
- [ ] 设置：默认参数表单首帧显示上次值。

## 移动端（390px 视口必查）
- [ ] 导航可点（touch），主题下拉一次点开。
- [ ] 难度下拉一次点开（v-touch-open 生效），无清空 × 误触。
- [ ] 播放键/倍速/循环/原文按钮居中，拇指可及。
- [ ] 所有自绘按钮 type="button"（否则表单内点击=整页刷新）。

## 主题
- [ ] 深空星夜：星空/流星/网格/光斑正常；白天：飘云/鸟群/光束/光尘正常。
- [ ] 切换后刷新，主题保持（localStorage `el-theme`）。
- [ ] 无白底白边回归（快速法：截全页找 rgb(255,255,255) 与 #dcdfe6 的绘制者；检查右侧滚动条）。

## 弹窗与提示
- [ ] 新增主题弹窗、删除确认框为深/浅主题对应样式，可正常输入与取消。
- [ ] 消息气泡（成功/错误）颜色随主题。

## 已知的历史坑（改到相关代码时加倍小心）
- `<script setup>` 顶层变量是**每实例一份**——跨卡片共享的状态必须放独立模块（见 utils/audioBus.js）。
- el-menu 在手机上点不动 → 导航必须用 router-link 自绘。
- el-select 触屏要点两次 → 必须挂 v-touch-open。
- EP 默认亮色主题到处漏白 → 全局覆盖规则在 style.css，别删。
- 浏览器在页面不可见时会暂停 rAF 与动画时间线（自动化检测时注意，非 bug）。
