# English Listening Gym — Docker 部署方案

## 概述

将英语听力训练应用以容器化方式部署到 **Ubuntu 24.04 LTS** 服务器。

| 组件 | 技术 | 端口 |
|------|------|------|
| 后端 | FastAPI + Uvicorn (Python 3.11) | `8000` |
| 前端 | Vue 3 + Vite (构建后由 Nginx 托管) | `80` |
| 数据持久化 | Docker Volume | `english_listening_data` |
| LLM | 智谱 GLM (在线 API) | — |
| TTS | Edge-TTS (在线服务) | — |

---

## 架构

```
                          ┌──────────┐
  Browser ──► :80 ──► Nginx (frontend)
                          │  /api/*  │
                          ▼          │
                       backend:8000  │
                          │          │
                     FastAPI + edge-tts + ChromaDB
                          │
                     Volume: data (SQLite / audio / Chroma)
```

- 前端 SPA 静态文件由 **Nginx** 直接托管，性能最佳
- `/api/*` 请求反向代理到后端容器
- 后端数据（SQLite、音频文件、向量库）通过 **Docker Volume** 持久化，重启不丢失
- LLM 和 TTS 均使用在线 API，容器需能访问公网

---

## 前提条件（服务器）

- Ubuntu 24.04 LTS
- root 或 sudo 权限
- 公网访问（LLM API / Edge-TTS）
- （可选）域名指向服务器 IP

## 快速部署（一键脚本）

```bash
# 1. 克隆或上传项目到服务器
git clone https://github.com/TslldBaoGe/english_listening_gym.git
cd english_listening_gym

# 2. 安装 Docker（如未安装）
sudo bash deploy/install-docker.sh
# 按提示登出再登入（或执行 newgrp docker）

# 3. 配置 API Key
cp .env.example .env
nano .env   # 填入 ZHIPU_API_KEY

# 4. 一键部署
bash deploy/deploy.sh
```

部署完成后：
- 浏览器访问 `http://<服务器IP>` 即可使用
- 后端 API 地址 `http://<服务器IP>:8000`

## 手动分步部署

### 1. 安装 Docker + Compose

```bash
# 卸载旧版
for pkg in docker.io docker-doc docker-compose docker-compose-v2 podman-docker containerd runc; do
  sudo apt-get remove -y $pkg
done

# 安装依赖
sudo apt-get update
sudo apt-get install -y ca-certificates curl

# 添加 Docker 官方源
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu noble stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 当前用户加入 docker 组（免 sudo）
sudo usermod -aG docker $USER
newgrp docker   # 或登出重新登录
```

### 2. 配置环境变量

```bash
cp .env.example .env
nano .env
```

`.env` 文件内容：

```
ZHIPU_API_KEY=your_actual_api_key_here
LLM_MODEL=glm-4-flash
```

> **注意**：API Key 只在容器内使用，不会提交到 git。

### 3. 构建并启动

```bash
# 构建镜像（首次约 5-10 分钟）
docker compose build

# 启动服务（后台）
docker compose up -d

# 查看日志
docker compose logs -f

# 查看状态
docker compose ps
```

### 4. 验证部署

```bash
# 前端
curl -s -o /dev/null -w "%{http_code}" http://localhost
# 应返回 200

# 后端 API
curl -s http://localhost:8000/api/meta | head -c 200
# 应返回 JSON 元数据
```

## 数据持久化

数据存储在 Docker 命名卷 `english_listening_data` 中，包括：

| 路径 | 内容 |
|------|------|
| `/app/data/app.db` | SQLite 数据库（句子、测验记录、设置） |
| `/app/data/audio/*.mp3` | 生成的音频文件 |
| `/app/data/chroma/` | ChromaDB 向量库（句子去重） |

```bash
# 备份数据
docker run --rm -v english_listening_data:/data -v $(pwd):/backup alpine tar czf /backup/el-data-$(date +%Y%m%d).tar.gz -C /data .

# 恢复数据
docker run --rm -v english_listening_data:/data -v $(pwd):/backup alpine tar xzf /backup/el-data-20250101.tar.gz -C /data
```

## 安全建议

1. **API Key 保护**：使用 `.env` 文件，不要提交到 git
2. **防火墙**：仅开放端口 `80`（前端），`8000` 不需要对外开放
3. **反向代理 HTTPS**（推荐）：

```bash
# 使用 Caddy（自动 HTTPS）
sudo apt-get install -y caddy
# /etc/caddy/Caddyfile:
# your-domain.com {
#     reverse_proxy localhost:80
# }

# 或使用 Nginx + certbot
```

4. **数据库备份**：定期备份 `english_listening_data` 卷

## 常见问题

**Q: 启动后访问不了？**

```bash
# 检查容器状态
docker compose ps
# 检查日志
docker compose logs backend
docker compose logs frontend
# 检查防火墙
sudo ufw status
sudo ufw allow 80/tcp
```

**Q: 前端报 502 Bad Gateway？**

后端尚未就绪，等待 10-15 秒后刷新。或检查后端日志：
```bash
docker compose logs backend
```

**Q: 如何更新代码？**

```bash
git pull
docker compose build
docker compose up -d
```

**Q: Edge-TTS 在容器内发声吗？**

Edge-TTS 调用的是微软在线 API（`speech.microsoft.com`），容器内只需能出网即可，无需声卡设备。
